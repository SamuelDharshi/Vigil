# Demo Script (3 minutes)

Requires a RYO-CHAN key. Show only real output from a recorded run.

- 0:00 Problem: market signals rarely come with a reasoning trail you can check.
- 0:20 Run research:run; open a snapshot and show sources, timestamps and unavailable fields.
- 0:50 Show the bullish, bearish and conflict lists for one decision.
- 1:25 Show confidence and each risk check.
- 1:50 Show the practice BUY or the NO_TRADE reason, whichever really occurred.
- 2:20 Run replay() and verifyChain(); edit one record and show the chain break. Show an on-chain anchor only if one exists.
- 2:45 Close: Vigil measures its own hypotheses, uses practice trades only and keeps missing data missing.
